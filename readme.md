# Student Academic Performance Analysis Using R

## Introduction
This project analyses the academic performance of 10 students
in five different subjects using R programming.

## Objectives
- Create a student marks dataset.
- Calculate mean, median and mode.
- Calculate variance and standard deviation.
- Identify highest and lowest scoring students.
- Generate graphs and interpret results.

## Subjects
1. Mathematics
2. Statistics
3. Computer Science
4. English
5. Electronics

## Tools Used
- R Programming
- RStudio
- Base R functions

## Graphs
1. Subject-wise Average Marks
2. Total Marks of Students
3. Distribution of Marks

## Findings
- Computer Science has the highest subject average.
- Student 8 obtained the highest total marks (473).
- Student 7 obtained the lowest total marks (301).
- English has the lowest variance.

## Conclusion
R programming helps analyse student performance
using statistical calculations and graphical representations.
